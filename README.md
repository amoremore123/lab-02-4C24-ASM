# lab-02-4C24-ASM

Descripción breve del proyecto

Este proyecto corresponde al laboratorio 02 de Git, donde se practican comandos básicos para administrar un repositorio local y remoto.

## Getting Started

Instrucciones para empezar el proyecto

1. Clonar el repositorio.
2. Ingresar a la carpeta del proyecto.
3. Realizar los cambios necesarios en los archivos.
4. Agregar los cambios al Stage.
5. Crear un commit.
6. Subir los cambios al repositorio remoto mediante `git push`.
7. Actualizar el proyecto mediante `git pull`.
